# 非线性回归分析
$$
y=f(x, \theta)+\varepsilon
$$
## 原理对比

|        |             线性回归             |           非线性回归            |
| :----: | :--------------------------: | :------------------------: |
|  函数形式  |          直线、平面或超平面           |           曲线、曲面            |
| 计算复杂度  |           简单，有闭式解            |        复杂，通常需要迭代求解         |
| 参数估计方法 |            最小二乘法             |    非线性最小二乘法、最大似然估计、迭代算法    |
|  可解释性  |      系数直接表示变量对因变量的影响程度       |     参数解释相对复杂，需要结合函数形式      |
| 模型稳定性  |          稳定性好，不易过拟合          |        稳定性较差，容易过拟合         |
| 样本量要求  |          对样本量要求相对较低          |         通常需要较大的样本量         |
|  使用场景  |        变量间关系简单、线性趋势明显        |      变量间关系复杂、存在非线性趋势       |
|  常见类型  |     简单线性回归、多元线性回归、多项式回归      | 指数回归，对数回归，幂函数回归，Logistic回归 |
|   优点   | j计算简单快速，结果易于理解，统计推断完善，不易过拟合  | 拟合能力强，能处理复杂关系，预测精度高，应用范围广  |
|   缺点   | j只能处理线性关系，对非线性数据拟合差，模型表达能力有限 |  计算复杂，容易过拟合，参数初值敏感，可能无法收敛  |
| 评估指k标  |   $R^2、调整R^2、AIC、BIC$、F统计量   |   $R^2、AIC、BIC$、均方误差、残差    |
| j实际应用  |    经济学分析，市场研究，质量控制，简单预测模型    | 生物学增长模型，药物动力学，工程系统建模，机器学习  |
非线性回归类型问题可分为：可线性变换和不可线性变换
## 可线性变化
1. 确定曲线模型

| 曲线名称 |                 曲线拟合模型表达式                  |
| :--: | :----------------------------------------: |
| 二次曲线 |      $y=\beta_0+\beta_1x+\beta_2x^2$       |
| 三次曲线 | $y=\beta_0+\beta_1x+\beta_2x^2+\beta_3x^3$ |
| 对数曲线 |           $y=\beta_0+\beta_1lnx$           |
| 指数曲线 |          $y=\beta_0e^{\beta_1x}$           |
| 复合曲线 |            $y=\beta_0\beta_1^x$            |
| 增长曲线 |         $y=e^{\beta_0+\beta_1^x}$          |
| S曲线  |     $y=e^{\beta_0+\frac{\beta_1}{x}}$      |
	模型选择准则：
	- AIC（赤池信息准则）：越小越好
	- BIC（贝叶斯信息准则）：越小越好
	- 调整$R^2$：考虑参数个数的影响
2. 设置参数和初始值
   初始值计算：
   - 选择合适的初始值设置方法
   - 计算各参数的初始值估计值
   - 检查初始值的合理性
   约束设定：
   - 根据实际意义设置参数约束
   - 确保初始值在约束范围内
   - 避免过于严格的约束
   迭代优化：
   - 运行非线性回归算法
   - 监控收敛过程
   - 必要时调整初始值或约束
