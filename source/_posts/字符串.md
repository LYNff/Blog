# 字符串

***c语言中利用字符数组来表示字符串，在字符串处理时不以字符数组的长度为准，而是检测字符'\0'来判别字符串是否处理完毕。***

#### 一. 字符数组和字符串

1. ###### 字符数组的定义和初始化

	```c
	char str[]={'c','H','I','N','A','\0'};
	char str[]={'c','H','I','N','A'};
	char str[]={"CHINA"};
	char str[]="CHINA";
	```

	上面四个定义和初始化方式等价。<span style="color: red;">**注意：**</span>数组str所占内存空间是6字节。
	如果字符数组定义及初始化语句改为：

	```c
	char str[10]="CHINA";
	```

	则数组str的后面5个元素都是'\0'。
	字符串到第一个'\0'结束。例如：

	```c
	char c[]="abc\0oxyz";
	printf("%d %d\n",strlen(c),sizeof(c));
	```

	则数组c的长度为8，而其中存放的字符串为"abc"。
	输出结果为3，8

2. ###### 字符数组的输入输出

	字符数组的输入/输出方式有2种。

	- 单个字符的输入、输出，使用格式化输入/输出函数 scanf()/printf()的格式符"%c"可以逐个字符的输入、输出。

		```c
		char ch;
		scanf("%c",&ch);
		prirntf("%c",ch);
		```

	- 字符串的整体输入、输出。在scanf()函数和printf()函数中用格式符"%s"输入、输出字符串，==对应的参数应该是数组名即数组的起始地址，不能是数组元素。==
		```
		char str[a];
		scanf("%s",str);
		```

		<span style="color: red;">注意：scanf()函数用格式符"%s"输入时，遇空格、Tab、回车符终止，并写入字符串结束标志'\\0'</span>

#### 二. 字符串输入/输出函数

1. ###### 单个字符的输入/输出函数

	- getchar(). getchar()函数可以从键盘读取一个字符
		```c
		char ch;
		ch=getchar() //使用getchar()函数读取一个字符并赋值给字符变量ch
		```

		注意：getchar()函数没有参数，但使用时不能缺少小括号"( )"。

	- 字符输入函数getch()。getch()函数可以从键盘中读取一个字符，==但不显示在屏幕上==。**getch()函数头文件为conio.h**
		```c
		char ch;
		ch=getch(); //使用getch()函数读取一个字符给字ch，但屏幕上不回显
		```

		使用getch()函数输入密码：
		```c
		#include <stdio.h>
		#include <conio.h> //getch()函数头文件
		int main(void)
		{
		    char ch, pwd[100];
		    int i = 0;
		    while ((ch = getch()) != '\r')
		    {
		        putchar('*');
		        pwd[i++] = ch;
		    }
		    pwd[i] = '\0';
		    printf("\n%s\n", pwd);
		    return 0;
		}
		```

	- 字符串输出函数putchar()，putchar()函数用于向终端输出字符。
		``` c
		char ch='x';
		putchar(ch); //等价于printf("%c",ch);
		putchar('\n');
		```

2. ###### 字符串的输入/输出函数

	- 字符串输入函数gets(). gets()函数原型为：
		```c 
		char *gets(char *str);
		```

		功能：读入一串以回车结束的字符，顺序存入到以str为首地址的内存单元，最后写入字符串结束表示'\0'。
		**gets()和scanf()函数一样，存在一种潜在的安全隐患，即gets()函数和scanf()函数限制输入字符串的长度。**

	- 字符串输入函数fgets()函数。函数原型为：
		```c
		char *fgets(char *buf,int bufsize,FILE *stream);
		```

		功能：从stream流读取以'\n'结尾的一行字符（包括'\n'在内）存到缓冲区buf中，读取字符的个数最多为bufsize-1。在读取字符的末尾添加一个'\0'组成完整的字符串。
		从键盘中输入一个人名：

		```c
		#include<stdio.h>
		int main(void)
		{
		    char name[10];
		    printf("Enter your name:\n");
		    fgets(name,sizeof(name),stdin);
		    printf("Hello %s!\n",name);
		    return 0;
		}
		```

		*字符串输入时，应尽量使用fgets()函数，避免使用gets()函数。*

	- 字符串输出函数puts()函数。函数原型为：
		```c
		int puts(char *str);
		```

		功能：输出内存中从地址str起的若干字符，知道遇到'\0'为止，最后输出一个换行符。
		puts()函数和printf()函数以格式符"%s"输出字符串的区别：前者逐个输出字符到'\0'结束时自动输出一个换行符，后者逐个输出字符到'\0'结束，不会自动输出换行符。

3. ###### 字符串处理函数

	*使用字符串处理行数，应包括头文件<string.h>*

	- 字符串长度函数
		函数原型为：

		```c
		int strlen(char *str);
		```

		strlen是统计字符串长度的函数。其函数的返回值为字符串中的实际包含字符的个数，不包括'\0'在内。
		```c
		char str[10]="China";
		printf("%d %d\n", strlen(a), strlen("China"));
		printf("%d %d\n", sizeof(a), sizeof("China"));
		```

		输出结果为 5 5和10 6

	- 字符串复制函数
		函数原型为：

		```c
		strcpy(char  s1[],char s2[]);
		strncpy(char s1[],char s2[],int maxien);
		```

		strcpy的作用是将以s2为首地址的字符串复制到以s1为首地址的字符数组中;
		strncpy的作用是将以s2为首地址的字符串中前n个字符复制到以s1为首地址的字符数组中
		说明：

		- 在调用strcpy函数时，第一个参数必须是数组名（如str1），第二个参数可以是字符数组名，也可以是一个字符串常量。
		- 复制字符串时连同字符串尾部的结束符'\0'也一并复制到str1中。

	- 字符串连接函数
		格式：

		```c
		strcat(char s1[],char s2[]);
		```

		函数将以s2为首地址的字符串连接到s1字符数组中的字符串后面。连接后的字符串存放在s1字符数组中，返回的是字符数组s1的首地址。
		注意：

		- 连接前两个字符串都有'\0'，连接时会将s1后的'\0'覆盖，只在连接后的新字符串的最后保留一个'\0'。
		- 调用该函数时，s1一般为字符数组，s2可以是字符数组，也可以是字符串常量。

	- 字符串比较函数
		函数原型：

		```c
		int strcmp(char *str1,char *str2)
		```

		该函数的功能是比较字符串str1和字符串str2的大小。比较方法为：依次对str1和str2对应位置上的字符按ASCII码值的大小进行比较，知道出现不同字符或遇到字符串结束标志'\0'。

	- 字符串转换函数
		<center>表1 字符串转换函数</center>

		|            函数原型             |             函数说明              |
		| :-----------------------------: | :-------------------------------: |
		|   int atoi(const char *nptr);   |  将nptr指向的字符串转换为int类型  |
		|  long atol(const char *nptr);   | 将nptr指向的字符串转换为long类型  |
		| double atof(const char  *nptr); | 将nptr指向的字符串转换为doble类型 |

		使用atoi()函数、atol()函数和atof()函数，需要包含头文件<stdlib.h>。

#### 三. 字符处理函数

字符处理函数库包含了用于对字符数据进行处理的标准库函数。使用这些函数时，需要包含头文件<ctype.h>
<center>表2 常用字符处理函数</center>

|       函数原型       |                           功能描述                           |
| :------------------: | :----------------------------------------------------------: |
| int isdigit(int c);  | 检查参数c是否为阿拉伯数字0到9。<br />若参数c为阿拉伯数字，则返回TRUE，否则返回NULL(0)。 |
| int islower(int c);  | 检查参数c是否为小写英文字母。<br />若参数c为小写英文字母，则返回TRUE，否则返回NULL(0)。 |
| int isupper(int c);  | 检查参数c是否为大写英文字母。<br />若参数c为大写英文字母，则返回TRUE，否则返回NULL (0)。 |
| int isalpha(int c);  | 检查参数c是否为英文字母。<br />若参数c为英文字母，则返回TRUE，否则返回NULL(0)。 |
| int isalnum(int c);  | 检查参数c是否为英文字母或阿拉伯数字。<br />若参数c为字母或数字，则返回TRUE，否则返回NULL(0)。 |
| int tolower(int c);  | 如果c时大写字母，则将c转换为对应的小写字母后返回。否则返回未改变的c。 |
| int toupper(int c);  | 如果c时小写字母，则将c转换为对应的大写字母后返回。否则返回未改变的c。 |
| int isspace(int c);  | 检查参数c是否为空白字符，也就是判断是否为空格、换行符、回车符、水平制表符、垂直制表符或换页符。<br />若参数c为空白字符，则返回TRUE，否则返回NULL(0)。 |
| int iscntrl(int c);  | 检查参数c是否为ASCII控制码，也就是判断c的范围是否在0到30之间。<br />若参数c为ASCII控制码，则返回TRUE，否则返回NULL(0) |
| int isprint(int c);  | 检查参数c是否为可打印字符。<br />若参数c为==包括空格在内==的可打印字符，则返回TRUE，否则返回NULL(0)。 |
| int sigraphy(int c); | 检查参数c是否为可打印字符。<br />若c是==除空格外==的所有可打印字符，则返回TRUE，否则返回NULL(0)。 |
