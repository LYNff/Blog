# 结构体、共用体和枚举类型

### 一. 结构体变量

1. ###### 结构体的定义

	一般形式：
	```c
	struct 结构体标识符
	{
	    数据类型 成员名1;
	    数据类型 成员名2;
	    ......
		数据类型 成员名n;
	};
	```

	其中，struct是c语言的关键字，表示定义结构体类型。
	结构体类型定义只是声明了一种数据类型，并未声明结构体类型的变量，==编译器此时不为其分配内存单元==。

2. ###### 结构体变量的定义

	（1）先定义结构体类型，再定义该结构体类型变量。（推荐）
	```c
	struct student
	{
	    char number[10];
	    char name[20];
	    char sex;
	    int age;
	};
	struct student stu1; //定义结构体类型变量stu1
	```

	（2）在定义结构体类型的同时定义该类型变量。
	```c
	struct student
	{
	    char number[20];
	    char name[20];
	    char sex;
	    int age;
	}stu1,stu2;
	```

	（3）不定义结构体类型标识符，直接定义结构体变量。
	```c
	struct
	{
	    char number[20];
	    char name[20];
	    char sex;
	    int age;
	}stu1;
	```

	定义结构体变量后，系统为其分配内存空间，结构体变量各成员按顺序存储，每个成员**分别**占有自己的内存单元。
	可以用sizeof运算符计算该变量或该种类型的变量所占存储空间的字节数。

	<span style="color: red;">注意：一个结构体变量所占内存空间一般 大于等于该结构体变量各成员所占字节之和。
	</span>
	*一般的计算机系统要求数据必须从某个数（通常为2、4或8）的整数倍的地址开始存放。这种对数据对象存储位置的特殊要求成为**“对齐”***。
	**==结构体的长度必须为结构体的自身对齐值的整数倍==**，不够就补空字节。
	结构体的对齐值取其成员最大的对齐值。

	```c
	struct student
	{
	    char number[10];
	    char name[20];
	    char sex;
	    int age;
	};
	struct student stu1;
	```

	**对于上面结构体，sizeof(stu1)为48而不是45！**

3. ###### 结构体变量的初始化

	一般形式：
	*结构体类型 结构体变量名={初始值表}；*

	```c
	struct student stu1 = {"10010101","张三",'M',20};
	```

4. ###### 结构体的嵌套

	嵌套的结构体就是在一个结构体内包含另一个结构体作为其成员。
	```c
	struct date
	{
	    int year;
	    int month;
	    int day;
	};
	struct student
	{
	    char number[20];
	    char name[20];
	    char sex;
	    struct date birthday;
	};
	```

	如果要修改stu1的出生年份，以下列形式进行访问：
	```c
	stu1.birthday.year=1999;
	```

5. ###### 结构体变量的引用

	结构体变量的引用分为**结构体成员变量的引用**和**结构体变量整体引用**两种。
	（1）结构体成员变量的引用
	语法格式为：     结构体变量名.成员名
	其中，运算符" . "为成员运算符，表示引用结构体变量的某个成员。在所有的运算符中，" . "的优先级是最高的，与"( )" "[ ]"同级。

	<span style="color: red;">注意：c语言规定，不允许将一个结构体变量作为整体进行输入/输出操作</span>

	（2）结构体变量的整体引用
	结构体变量可以作为整体赋值给同类型的结构体变量，即把一个变量的各成员分别赋值给另一同类型变量的相应成员。

	```c
	struct student stu1 = {"10010101","张三",'M',20,{80,90,88}};
	struct student stu2;
	stu2=stu1;
	```

6. ###### 用typedef声明数据类型

	*为了增强程序的可读性，可以使用关键字typedef声明一个新的类型名，也就是说，允许用户为已有的数据类型起“别名”，从而使数据类型的属性更加直观。*

	```c
	typedef int INTEGER;
	typedef float REAL;
	
	INTEGER n; //n为int类型
	REAL x; ///x为float类型
	
	typedef int ARR[20];
	ARR a,b; //等价于 int a[20],b[20];
	```

	当然，还可以使用typedef为结构体定义一个别名。
	```c
	typedef struct student
	{
	    char number[20];
	    char name[20];
	    char sex;
	    int age;
	}STUDENT;
	```

	其中，**STUDENT表示struct student类型**。

### 二. 结构体数组

1. ###### 结构体数组的定义

	定义student结构体类型的数组：
	```c
	struct student stu[30];
	```

	stu为一个包含30个元素的数组，其中每个元素都是结构体student类型变量。

2. ###### 结构体数组的初始化

	```c
	struct student stu[3]={{"10010101","张三",'M',20,{80,90,100}},
	                       {"10010102","李四",'F',18,{78,92,86}},
	                       {"10010103","王五",'M',19,{90,60,78}}
	                      };
	```

### 三. 结构体和指针

1. ###### 指向结构体变量的指针

	```c
	struct student stu1;
	struct stdent *p;
	p=&stu1;
	
	struct student *p=&stu1; //定义结构体指针p，同时进行初始化
	```

	c语言规定了另一种访问结构体成员的运算符：指向运算符。访问形式为：
		*结构体指针 -> 成员名*

	```c
	p->age=20;
	```

2. ###### 指向结构体数组的指针

	```c
	struct student stu[n];
	struct student *p=stu;
	```

### 四. 结构体与函数

1. ###### 结构体作为函数参数

	结构体作为函数参数进行传递有两种方式：值传递和地址值传递。一般情况下，应使用地址值传递，只有当结构体较小时使用值传递。
	```c
	void print_stu(struct student stu);
	```

2. ###### 返回结构体的函数

	函数的返回值可以为结构体类型
	```c
	struct student input_stu(void);
	```

### 五. 结构体指针作为函数参数

*结构体指针作函数参数传递的是结构体的地址，通常地址传递的效率较高。*

```c
void print_stu(struct stuPE *p,int n);
```

### 六. 共用体

共用体也称联合体，是一种构造数据类型，它是将不同类型的变量存放在同一内存区域内。共用体的类型定义、变量定义及引用方式与结构体相似，但它们有着本质的区别：**结构体变量**的各成员占用==连续的不同存储空间==，而**共用体变量**的各成员占用==同一存储区域==，这些数据可以互相覆盖。

1. ###### 共用体类型的定义

	一般形式为：
	```c
	union 共用体名
	{
	    数据类型 成员名1;
	    数据类型 成员名2;
	    ......
		数据类型 成员名n;
	};
	```

	其中，union是c语言中的关键字。与定义结构体变量一样，定义共用体也为三种方式。
	定义了共用体变量后，系统将给它分配内存空间。共用体变量中的各成员占用同一存储空间，共用体变量所占用的存储单元为==占用字节数最大的成员的长度==。

2. ###### 共用体变量的引用

	虽然共用体数据可以在同一内存空间中存放多个不同类型的成员，==但在某一时刻只能存放其中的一个成员==。
	```
	u1.c='x';
	u1.n=100;
	u1.f=12.3;
	```

	此时只有u1.f是有效的，因为后面的赋值语句将前面的共用体数据覆盖了。
	<span style="color: red;">注意：</span>

	- 共用体变量的成员共用同一块内存单元，共用体变量与共用体成员的地址是相同的。

	- 在给共用体成员赋值时，只有最后一次赋值起作用。

	- 在定义共用体时，不能同时对其初始化。如有需要，也只能对它的第一个成员赋初始值。
		```c
		union data u1 = {'x',100,12.3}; //错误，不能全部成员初始化
		union data u2 = {'x'}; //正确，可以对第一个成员初始化
		```

	- <span style="color:red;">**共用体变量不能作为函数参数，也不能作为函数的返回值**</span>

### 七. 枚举类型

1. ###### 枚举类型的定义

	一般形式为：
	*enum 枚举类型名 { 枚举常量列表 }；*

	```c
	enum weekday{SUN,MON,TUE,WED,THU,FRI,SAT};
	```

	这些枚举常量并不是字符串也不是数值，而仅仅只是一些用户自己定义的标识符，所代表的含义，完全由程序员决定，并在程序中对它们作相应的处理。

2. ###### 枚举类型变量的定义与引用

	```c
	enum weekday today,tomorrow;
	enum weekday{SUM,MON,TUE,WED,THU,FRI,SAT} today,tomorrow;
	```

	以上对于枚举类型weekday的声明，枚举变量的值只能是Sunday到Saturday之一。
	```c
	today=MON;
	tomorrow=TUE;
	```

	说明：

	- 枚举常量时有值的，编译器按定义时的顺序将它们赋值为0，1，2，3，...。

	- 定义枚举常量时也可以显示地赋给它某个正整数，例如：
		```c
		enum weekday {Sunday=7,Monday=1,Tuesday,Wednesday,Thurday,Friday,Saturday};
		```

		指定Sunday为7，Monday为1，以后按顺序一次加1，Saturday=6；

	- 枚举类型可以进行关系运算、赋值运算。
		```c
		if(today==MON)...
		if(today>SUN)...
		today=FRI;
		```
