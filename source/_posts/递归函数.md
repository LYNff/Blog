# 汉诺塔

#### 题目：假设汉诺塔有n个圆盘，3根石柱分别命名为A、B、C。可以这样来考虑圆盘移动：

（1） 先将A柱上的n-1个圆盘移动到B柱上。
（2） 再将A柱上的最后一个圆盘移到C柱上。
（3） 最后将B柱上的n-1个圆盘移到C柱上。
这样就将原来要移动n个圆盘的问题变成了移动n-1个圆盘的问题。最终要实现将A柱上的圆盘全部移到C柱上，同时每次只能移动一个圆盘，小圆盘必须在大圆盘上面。

```c
#include <stdio.h>
void mov(char a, char b);
void Hanoi(int n, char a, char b, char c);
int main(void)
{
    int n;
    printf("Enter the number of disks:\n");
    scanf("%d", &n);
    Hanoi(n, 'A', 'B', 'C');
    return 0;
}
void mov(char a, char b)
{
    printf("%c--->%c\n", a, b);
}
void Hanoi(int n, char a, char b, char c)
{
    if (n == 1)
        mov(a, c);
    else
    {
        Hanoi(n - 1, a, c, b); // 先将A柱上的n-1个圆盘移动到B柱上
        mov(a, c);             // 再将A柱上的最后一个圆盘移到C柱上
        Hanoi(n - 1, b, a, c); // 最后将B柱上的n-1个圆盘移动到C柱上
    }
}
```

在实现递归时，可以不去考虑实现递归的过程细节，只需写出递归公式和递归结束条件（即边界条件）。递归程序容易理解和书写，但是在时间上和空间上的开销较大。
