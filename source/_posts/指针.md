# 指针

## 一. 变量的指针和指针变量

*指针实际上就是地址，因此==变量的指针就是变量的地址==。*

1. ##### 定义指针变量的一般形式为： 类型名 *指针变量名	例如：

	```c
	int *i_pointer; //定义整型指针变量i_pointer
	float *f_pointer; //f_pointer是指向单精度型数据的指针变量
	char *c_pointer; //c_pointer是指向字符型数据的指针变量
	```

2. ##### 指针变量的赋值：只需要把被指向变量的首地址赋给指针变量即可。    例如：

	```c
	int i,*i_pointer;
	i_pointer=&i; //将变量i的地址存放到指针变量i_pointer中
	```

	**不能将一个整型常数赋给一个指针变量！**

	```c
	int &i_pointer = 0x0012FF74; //此为错误的赋值
	```

	该语句的原意是想将地址0x0012FF74作为指针变量i_pointetr的初值，但*==编译系统并不把0x0012FF74认为是地址（字节编号）==*，而是认为是整数，两边类型不匹配。此时必须进行**强制类型转换**。	例如：

	```c
	int *i_pointer = (int *)0x0012FF74;
	```

	这样，系统就会将其视为整型数据的地址并赋给整型指针变量。
	**<span style="color: red;">注意:</span>**由于指针变量里面可以存放任何地址，因此必须保证它存放的是一个可以安全访问的地址，同样，如果使用==未经初始化的指针变量==，也可能会造成系统混乱，甚至死机。

3. ##### 指针的运算

	- 两个与指针有关的运算符：
		- &：取地址运算符
		- *：指针运算符（或称简介访问运算符）

	这两个运算符优先级相同，按自右向左的方向结合。如**&a为变量a的地址，*p为指针变量p所指向的存储单元。***

​	**<span style= "color:red;">注意：</span>**在指针中，“ * “有两种含义，一种是==定义指针变量的地址==，另一种是==指针运算符==，判断的依据是” * “前是否有数据类型。	例如：
```c
int *i_pointer; //定义指针变量的地址，仅表示i_pointer是指针变量
*i_pointer = 10; //指针运算符，表示指针变量i_pointer所指向的变量
```

- 指针的加减运算
	*指针加减一个整数值，或者两个指针值相减，一般来说，两个指针值相加是没有意义的。*

```c
#include <stdio.h>
int main(void)
{
    int a = 1, b = 2, c = 3;
    int *p = &c;
    for (int i = 0; i < 3; i++) // 按自右向左的顺序为变量分配存储空间
    {
        printf("(%p)==%d\n", p, *p);
        p++;
    }
    return 0;
}
```

==【运行结果】==
	（0012FF74）= 3
	（0012FF78）= 2
	（0012FF7c）= 1
不难看出，指针和整数 i 的加减法是**指针向前或向后移动 i 个对应指针变量类型的存储区域**

- 指针的关系运算
	c语言中引入一个特殊的地址——NULL。在ASCII码表中，其对应的值为0。它的意思是”空“，即指针不指向任何变量。如果指针和一个 特殊的”NULL“值比较，则十四判定指针是否未指向任何变量。	例如：

	if (p==NULL) ……

	或者 

	if (p==0) ……

4. ##### 指针访问数组元素

  *使用指针来处理数组具有代码简介，运行速度快等有点。*
  指针变量指向数组元素后，可以通过指针引用数组元素。    例如：

  ```c
  p=&a[3];
  *p=4; //对p当前所指向的数组元素a[3]赋予数值4
  ```

  <center>表1 一维数组中元素和地址的表示形式</center>

  |    表示形式    |        含义        |
  | :------------: | :----------------: |
  |    a+i,p+i     |   a[i]元素的地址   |
  | *(a+i),\*(p+i) | a[i]元素或p[i]元素 |

  访问一个数组元素，可以用一下方法：
  （1）下标法，如a[i]。用下表发比较==直观==，能直接知道是数组的第几个元素。
  （2）指针法，如*(a+i)或\*(p+i)。其中a是数组名，p是指向数组首元素的指针变量。
  **使用指针法访问数组元素，占用内存少，运行速度快**

  如要输出数组“int a[100]；"的前50个元素，可以使用：
  ```c
  p=a;
  while(p<a+50)
  {
  	printf("%d",*p);
  	p++;
  }
  ```

  **需要注意的是：\* , & , ++ , -- 都是属于同一优先级的，按==自右往左的方向结合。**

  <center>表2 指针运算的表示形式和含义</center>

  | 表示形式 |                             含义                             |
  | :------: | :----------------------------------------------------------: |
  |   p++;   |             使p指向数组的下一个元素，即p指向a[1]             |
  |   *p++   | 等价于*（p++)，先得到p所指向变量的值（即\*p），然后再使p的值加一。输出\*(p++)得到的是a[0]的值，且p指向a[1] |
  |   *++p   | 等价于*(++p)，先使p加1，指向下一个元素，再去\*p。输出\*(++p)则得到a[1]的值，且p指向a[1] |
  |  (*p)++  | 表示p所指向的元素值加1，即(a[0])++。注意：是元素值加1，而不是指针值加 1 |

  在用指针变量指向数组元素时，指针变量p可以指向有效的数组元素，但实际上它也可以指向数组以后的内存单元。如果有：

  ```c
  int b=5,a[10],*p=a; //指针变量p的初值为&a[0]
  printf("%d",*(p+10)); //目的是输出a[10]的值，但输出的却是b的值
  ```

  系统为整型数组a和变量b分配存储空间，数组a最后一个有效元素是a[9]，现在要求输出a[10]，但c语言编译系统并不把它认为非法。系统按p+10*d计算出要访问单元的地址，这显然是a[9]后面一个存储单元的地址，即变量b的存储单元，然后输出b中所存储的数值5。
  ==这样做虽然在编译时不会出粗，但应避免出现这样的情况。==这样会使程序得不到预期的结果，更有可能导致严重的后果。
  因此，==在使用指针变量指向数组元素时，应切实保证指向数组中的有效元素。==

5. ##### 字符指针

	*在c语言中，通常可以使用两种方法对字符串进行操作*
	（1） 使用字符数组存储。例如：

	```c
	char str[]={“welcome!”};
	printf("%s",str); //整体引用，输出字符串“welcome!”
	printf("%s",str+3); //整体引用，输出字符串“come！”
	printf("%c",str[1]); //逐个引用，输出字符串“e“
	```

	调用printf( )函数，以%s的格式输出字符串时，从地址对应的存储单元开始连续输出字符，直到遇见结束标记'\0'为止。

	（2） 使用字符型指针变量。
	**字符串常量首字符所占存储单元的地址，被称为字符串常量地址。**只要将字符串常量赋值给字符指针，就可使字符指针指向该字符串。

	```c
	char *s = "welcome!";
	```

	这里虽然没有定义字符数组，但==系统在内存中仍开辟了一段连续空间来存放字符串常量==，同时**字符串的最后一个字符的后面被自动加了一个'\0'**，从而在输出的时候能确定字符串的终止位置。

	可以对字符指针赋值，使它指其他的字符串，但是却不能对字符数组名赋值，例如：
	```c
	char *s,str[80];
	s="Hello!"; //正确，将字符指针指向字符串“Hello！”的首地址
	str="Hello!"; //错误，字符数组名为常量，不能对它赋值
	```

	<span style="color:red;">注意：定义字符指针后，如果没有对其赋值，指针值使不确定的，即不能明确它指向的内存单元。因此，如果引用未赋值的指针，可能会出现难以预料的结果</span>

	字符串拼接：
	```c
	#include <stdio.h>
	int main(void)
	{
	    char a[50] = "Welcome to ";
	    char b[] = "C lanugage";
	    char *pa = a;
	    char *pb = b;
	    while (*pa != '\0')
	        pa++;
	    while (*pb != '\0')
	    {
	        *pa = *pb;
	        pa++;
	        pb++;
	    }
	    *pa = '\0';
	    pa=a;
	    printf("%s\n", a);
	    printf("%s", pa);
	    return 0;
	}
	```

6. #####  指针作为函数参数

	###### （1）指针变量作函数参数接受变量地址

	指针变量作为函数参数并不是一定会改变主调函数中变量的值，这个在不同的程序中需要根据语句来具体分析：
	```c
	void swap(int *p1,int *p2)
	{
	    int temp;
	    if(*p1<*p2)
	    {
	        temp=*p1;
	        *p1=*p2;
	        *p2=temp;
	    }
	}
	```

	若主调函数中为 void swap(a,b);则a最终为较大值，b最终为较小值。
	```c
	void swap(int *p1,int *p2)
	{
	    int *temp;
	    if(*p1<*p2)
	    {
	        temp=p1;
	        p1=p2;
	        p2=temp;
		}
	}
	```

	此时对于主调函数的a,b的值==没有影响==。
	
	###### （2）指针变量作为函数参数接收一维数组地址
	
	*向函数传递一维数组的实质就是向函数传递以为数组首元素的地址。*
	
	<center>表3 形参和实参的结合的形式</center>
	
	|   形参   |   实参   |
	| :------: | :------: |
	|   数组   |  数组名  |
	|   数组   | 指针变量 |
	| 指针变量 |  数组名  |
	| 指针变量 | 指针变量 |

7. ##### 返回值为指针类型的函数

	*返回指针值的函数简称为指针函数。一般形式为：类型名 \*函数名（参数列表）;*
	求一维数组中的最大值：

	```c
	#include<stdio.h>
	int *max(int array[],int size)
	{
	    int *m=array,i;
	    for(i=0;i<size;i++)
	    {
	        if(array[i]>*m)
	            m=array[i];
	    }
	    return m;
	}
	int main(void)
	{
	    int a[]={6,4,2,1,7,8,18,5,0,9};
	    printf("This max is: %d\n",*max(a,sizeof(a)/sizeof(int)));
	    return 0;
	}
	```

	在max的左右两侧分别为*运算符和()运算符，()优先级高于\*,因此max先与()结合，很显然这是函数的形式。
	<span style="color:red;">注意：函数返回的指针所指向的数据不能够是函数内声明的变量，因为一个函数一旦运行结束，在函数内声明的变量就会消失。因此返回值为指针的函数必须返回一个函数结束运行后仍然有效的地址值。</span>

## 二. 指针的高级应用

#### （1）一维数组和二维数组的关系

二维数组可以视为一个特殊的一维数组，这个特殊一维数组的每个元素又是一个以为数组，所以==二维数组可以看作是”数组的数组“==。
二维数组"int a[3]\[4];"中的任一元素a[i]\[j]的实际存储地址为：
	**a+(i\*列数+j)\*sizeof(元素类型)**

#### （3）指向一维数组的指针变量

对于指向二维数组的指针变量有两种，一种是指向数组元素的==（元素指针）==，另一种则是指向行的==（行指针）==。对于第二种，p不是指向一个具体的数组元素，而是指向一个包含若干个元素的一维数组。这种指向一个若干个元素的一维数组的指针变量，称为指向一维数组的指针变量，也成为**行指针**。其定义格式为：
	*类型 （\*指针名）[数组长度]；*

```c
int (*p)[4]
```

p是一个行指针也称行地址。

#### （4）指针数组

指针数组中的每一个元素都是一个指针变量，它的值是一个地址。一维指针数组的定义形式为：
	*类型名 \*数组名[数组长度]；*

```c
int *p[4];
```

因为[]比*优先级高，所以p可以视为数组名，每个元素都是"int \*"类型的，表示此数组的每个元素都是指向整型数据的指针变量。
**引入指针数组的主要目的是方便管理同类型指针，它比较适合用于指向多个字符串，是字符串的处理更加灵活、方便。**

采用指针数组来处理字符串有以下好处。首先，如果将若干个字符串存放在一个二维数组中，必须按字符串中最长串的字符数俩来定义列数，而实际上各个字符串是不等长的，这样就造成了空间的浪费。如果采用指针数组可以==指向长度不同的字符串==，从而==克服空间浪费==上的问题。
其次，==指针（一个整型地址）需要的存储空间比完全复制字符串要少==，在只复制指针而不是整个字符数组时程序能执行得更快。最后，由于==字符串自身只能被存储一次==，若对字符串进行排序，对字符串所做的修改将会自动同步到排序结果中。

#### （5）指向指针的指针变量

指向指针的指针变量又称*二级指针变量*，要定义其，可以采用以下形式：
	*数据类型 \*\*指针变量名；*

```c
int **pp;
```

“*”的结合方向是自右往左的，因此"int **pp"等价于"int \*(\*pp)"。
指针素组和二维数组的使用

```c
#include<stdio.h>
int main(void)
{
    int a[5]={1,2,3,4,5};
    int *num[5]={&a[1],&a[2],&a[3],&a[4],&a[5]};
    int **p,i;
    p=num;
    for(i=0;i<5;i++)
    {
        printf("%d\t",**p);
        p++;
    }
    return 0;
}
```

#### （6）行指针作函数参数

如果函数参数为行指针，则实参和形参之间传递的就是行地址。

#### （7）指向函数的指针变量

c语言中的每一个函数在系统编译后，其目标代码连续存放在一段内存单元中。函数被调用时，就是从这段内存单元的起始地址开始执行目标代码的，该起始地址就是函数的入口地址，也称==函数的指针==。指向函数的指针变量的一般定义形式为：
	*函数类型 （\*指针变量名）（函数形参表）；*

```c
int (*p)(int,int);
```

使用指向翰苏的指针变量来调用函数
```c
#include<stdio.h>
void sum(int x,int y)
{
    int s=x+y;
    return s;
}
int main(void)
{
    int (*p)(int ,int );
    int c,d,t;
    printf("Please input a and b:\n");
    scanf("%d%d",&a,&b);
    p=sum; //p指向sum函数
    t=(*p)(c,d); //调用sum函数
    printf("The Sum is: %d\n",t);
    return 0;
}
```

t = (*p)(c,d);或者t = p(c,d);两者与t = sum(c,d)是等价的，所以结果也是一致的。
