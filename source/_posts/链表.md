# 链表

## 一. 动态存储空间的分配与回收

#### C语言提供了实现动态存储分配的标准库函数，定义在 stdio.h 里面

###### (1) 动态存储分配函数 malloc( )；

```c
void *malloc(unsigned size);//函数原型
```

​	该函数在内存的动态存储区中分配一段==连续空间==，==长度为size==。若是**分配成功**，则返回指向所分配空间起始地址的指针；若**分配不成功**，则返回**NULL**。

```c
if（p=(int *)malloc(n*sizeof(int))==NULL)
{
    printf("Not able to allocate memory. \n");
    exit(1);
}
```

**每次动分配都必须检查是否成功**。动态空间分配之后，不能越界使用，尤其不能越界赋值，否则可能引起非常严重的后果。

###### (2) <span style="color: red;">计数</span>动态存储分配函数 calloc( )；

```c
void *calloc(unsigned n,unsigned size);//函数原型
```

​	该函数在内存的动态存储区中分配==n个连续空间==，每一存储空间的长度为==size==，并且**分配后把存储区全部初始化为0**。若**分配成功**，则返回一个指向被分配内存空间其实地址的指针；若**分配不成功**，则返回**NULL**。

###### (3) 动态存储释放函数 free( )；

```c
void free(void *ptr)//函数原型
```

​	*内存空间一旦释放后不允许再通过该指针去访问已经释放的存储区，否则可能会引起严重错误！*

## 二. 链表概述

1. ##### 与数组的比较

	如果需要==快速访问数据==，*很少或不插入和删除元素*，就应该用**数组**；相反，如果需要==经常插入和删除元素==就需要使用链表结构。

2. ##### 链表的主要操作归纳

	(1) 建立链表

	(2) 结点的查找与输出

	(3) 插入一个结点

	(4) 删除一个结点

	(5) 删除链表

## 三. 建立和遍历链表

1. ##### 建立链表

	- 创建链表必须定义一个头指针，通常命名为*head*

	- 接下来创建结点（创建结点实际上就是根据结点的结构==为其分配存储空间==，空间的大小由结点中各成员占据的空间之和来决定）

		**因为在节点中包含了不同类型的数据成员，所以通常使用==结构体==**类型来表示

		```c
		typedef struct student
		{
		    char num[10];
		    int score;
		    struct student *next;
		}STUDENT;
		```

		接下来是建立链表的函数：

		```c
		STUDENT *create( )
		{
			STUDENT *p,*q,*head;
		    int i=1;
		    head=0 //将head设置为0，表示该链表为空链表
		    while(i<=4)
		    {
		        if(p=(STUDENT *)malloc(sizeof(STUDENT))==NULL) //创建一个新结点，将该结点地址保存在指针变量p中
		        {
		            printf("Not able to allocate memory. \n");
		            exit(1);
		        }
		        printf("Please input %d th student's ID and score: \n"，i);
		        scanf("%s%d",p->num,&p->score);
		        if(head==0) //如果链表此时为空链表，则修改头指针的值
		        {
		 			head=p;
		            q=p;
				}
		        else //如果链表此时已经有结点了，head≠0，则将该结点链接在链表的最后一个结点的后面
		        {
		            q->next=p;
		            q=p;
		        }
		        i++;
			}
			q->next=0; //链表的最后一个节点的next成员设置为0，表明链表无后继结点了
			return (head);
		}
		```

2. ##### 遍历链表

	*当需要对链表中的任一结点进行操作时，就必须从链表的头指针开始依次查找，这就是需要使用遍历链表的操作*

	- **遍历链表首先要找到链表的头结点**。而头结点的地址保存在链表的头指针head中。

		遍历链表的函数：

		``` c
		void travel(STUDENT *head)
		{
		    STUDENT *p;
		    int i=1;
		    printf("Output data: \n");
		    while(p!=0)
		    {
		        printf("The %d th node is: \n");
		        printf("%s %d \n",p->num,&p->score);
		        p=p->next; //p指向链表中的下一个结点
		        i++; //i用来统计链表中结点的个数
		    }
		}
		```

## 四. 插入和删除结点

1. ##### 在链表中插入结点

	分为三种情况：

	(1) 原链表是空链表，插入结点后，链表不再为空。

	(2) 新结点插入的位置在链表头结点的前面，则需要修改头指针的值。

	```c
	p->next=head; //将head中的地址（头节点地址）保存在p指向结点的next成员中
	head=p; //此时p所指向的结点为链表的头节点，使head指向该结点
	```

	(3) 插入新结点在链表的具体位置。

	- 将新节点插入在链表中间，首先要查找插入新结点的位置。

		假设链表中的结点已经按顺序排列好，有两个指针be和ne，分别指向插入结点位置的前后结点。

		```c
		p->next=ne; //将新结点与后继结点连接
		be->next=p; //将新结点链接进链表
		```

	*将结点插入到链表中，并保持链表上各个结点的升序关系：*

	```c
	STUDENT *insertnode(STUDENT *head,STUDENT *p)
	{
		STUDENT *be,*ne;
	    if(head==0) //第一种情况，链表为空时插入结点
	    {
	        head=p;
	        p->next=0;
	        return (head);
	    }
	    if(strcmp(head->num,p->num)>=0) //第二种情况，新结点插入在头结点的前面
	    {
	        p->next=head;
	        head=p;
	        return (head);
	    }
	    be=ne=head; //第三种情况，在链表中插入新结点
	    while(ne!=0&&strcmp(ne->num,p->num)<0) //查找插入新结点的位置
	    {
	        be=ne;
	        ne=ne->next;
		}
	    p->next=ne;
	    be->next=be;
	    return (head);
	}
	```

2. ##### 在链表中删除结点

	同样分为三种情况：

	(1) 原链表为空链表，无结点可删，提示错误信息。

	(2) 如删去的结点是链表的头结点，则需要修改头指针的值。

	```c
	head=p->next;
	free(p);
	```

	(3) 在链表中的其他位置删除结点。

	```c
	be->next=p->next;
	free(p);
	```

## 五. 删除链表

​	当链表完成了所有的操作后，如果不再继续使用，就应该将链表从系统中删除。

* 删除整个链表：

```c
void releasechain(STUDENT *head)
{
	STUDENT *p;
	while(head)
	{
		p=head;
		head=head->next;
		free(p);
	}
}
```
